# Documentation

**Sidebar Navigation Builder for Bricks** is a header template for Bricks Builder. It gives you a sidebar menu with sliding panels, dropdowns you can nest, a collapsible mode, an off-canvas mode, a top bar and a mobile menu.

This documentation covers version **3.0.2**.

## What it can do

* **Sliding panels.** A button opens a new panel that slides in, with Back and Home buttons. You can go as many levels deep as you like. Three levels is plenty for most menus.
* **Dropdowns.** Lists that open in place. You can put dropdowns inside dropdowns.
* **Collapsible sidebar.** Shrinks the sidebar to its icons, with tooltips.
* **Off-canvas, push content and top bar.** Hide the sidebar behind a menu button, push the page aside, or add a bar across the top.
* **Headroom.** The top bar hides when you scroll down and comes back when you scroll up.
* **Left or right.** Works with Bricks' left and right header positions.
* **Keyboard and screen readers.** Tab, Enter and Escape work, panels have labels, and focus outlines show.
* **Normal Bricks elements.** Everything is built from Bricks elements, so you can put images, query loops or templates in a panel.

## How you customize it

You change the sidebar in three places:

1. **JavaScript options** in the JS tab of the **Sidebar Options CSS/JS** code block. These turn features on and off, such as the collapsible sidebar or off-canvas mode. See [Sidebar Options](sidebar-options.md).
2. **CSS variables** in the CSS tab of the same code block. These set colors, sizes and spacing. See [Styling](styling.md).
3. **Attributes** on the **Sidebar Nav 3.0.2** block, the top element of the template. See [Attributes & Classes](attributes-and-classes.md).

You don't need to touch the **Sidebar CSS and JS** code block, except to [change the breakpoint](sidebar-options.md#change-the-breakpoint).

### Change an attribute

1. In the builder, select the **Sidebar Nav 3.0.2** block in the Structure panel.
2. Open the **Style** tab, then **Attributes**.
3. Find the attribute by its **Name** and change its **Value**.

The attributes are already on the block. To turn one off, clear its **Value** and leave the attribute where it is, so you can turn it on again later.
